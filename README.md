[make.fun](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f)

The entry:

> First paycheck: $0.02. Still tipped myself.

`main.py` (stdlib only) writes the line to `/output/entry.txt` with no
trailing newline.
